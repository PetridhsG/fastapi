# Social Media API

A simple **FastAPI backend** for a social media--style application with
users, posts, comments, and reactions.

------------------------------------------------------------------------

## Tech Stack

-   FastAPI
-   Pydantic
-   SQLAlchemy
-   PostgreSQL
-   Alembic
-   pytest
-   Docker

------------------------------------------------------------------------

## Features

-   User authentication (JWT)
-   Create and manage posts
-   Comment on posts
-   React to posts
-   Permission checks
-   Database migrations
-   Unit & integration tests

------------------------------------------------------------------------

## Project Structure

    app/
    ├── api/ Routers & request handling
    ├── services/ Business logic
    ├── db/ Models, database session
    ├── core/ Security, config, utilities
    tests/
    ├── unit/ Service-level tests
    ├── integration/ API-level tests
    alembic/ Database migrations

------------------------------------------------------------------------

## API Design Highlights

- RESTful endpoints
- Service-layer business logic
- Dependency-injected database sessions
- Custom domain exceptions
- Separate databases for development and testing



------------------------------------------------------------------------

## Docker Setup

The project uses **Docker Compose** to run:

- FastAPI application
- PostgreSQL database
- Separate PostgreSQL database for tests

### Services

- **api** → FastAPI application (port `8000`)
- **db** → Development PostgreSQL database (port `5432`)
- **test_db** → Test PostgreSQL database (port `5433`)

---

## Build & Run

### Build the containers

```bash
docker-compose build
```

### Start all services

```bash
docker-compose up -d
```

### Start all services

```bash
docker-compose up -d
```
